FAQ

Questions founders ask before we start

Do you work with self-hosted n8n or cloud?
Both. I prefer self-hosted via Docker/VPS for cost + control, but I can ship on n8n Cloud if you want zero-ops.
What if WhatsApp/Telegram changes their API?
All workflows have isolated channel adapters. One node changes, the rest stays. I document the swap so your team isn’t locked to me.
How do you guarantee no duplicate orders?
Redis locks + idempotency keys + validation nodes. Every intake is checked before it’s saved. Duplicates are rejected, not retried.
What’s the handover like?
Loom video + architecture diagram + a control surface your team already uses (Telegram bot / Sheet) — no one needs to open n8n.
